# Contributing to Kipchak

The repositories in this organisation are read-only mirrors. Development takes place on
[1x.ax](https://1x.ax/mamluk/kipchak), and pull requests opened on GitHub are not merged.

To report a problem, propose a change or ask a question, [contact Mamluk](https://mamluk.net/contact/). The
documentation is at [kipchak.dev](https://kipchak.dev).
